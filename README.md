## 1. 세팅 (10분, 한 번만)

1. **GitHub 가입** → https://github.com (무료)
2. 오른쪽 위 `+` → **New repository**
   - 이름: `argon-daily` · **Public** 선택 (무료 계정은 Public이어야 Pages 사용 가능) → Create
3. 새 저장소 화면에서 **uploading an existing file** 클릭 → 이 압축을 푼 폴더 안의 **모든 파일·폴더를 드래그** → Commit changes
   - `.github` 폴더가 숨김 폴더라 안 보이면: 맥 Finder에서 `Cmd + Shift + .` 으로 보이게 한 뒤 함께 드래그
4. **Settings → Pages** → *Build and deployment* 의 Source를 **GitHub Actions** 로 변경
5. **Settings → Actions → General** → 맨 아래 *Workflow permissions* 를 **Read and write permissions** 로 → Save
6. **Actions** 탭 → 왼쪽 `Argon 데일리 자동 갱신` → **Run workflow** 버튼 → 3~5분 뒤 초록 체크
7. 완료 화면의 `deploy` 박스에 뜨는 링크가 내 웹앱 주소입니다. 카톡 단톡방에 이 링크를 공유하면 끝.

> 이후엔 아무것도 안 해도 매일 2번 자동 실행됩니다. GitHub 예약 실행은 몰릴 때 10~30분 늦어질 수 있어요.

## 4. 손글씨 해설을 넣고 싶은 날 (선택)

`argon/config.json` → `notes` 에 날짜를 키로 추가하면 그날만 손글씨 해설이 쓰이고, 없으면 데이터로 자동 생성된 3줄 진단이 나갑니다(카드에 `AUTO` 표시).

```json
"notes": {
  "2026-10-20": {
    "mac": {"title": "오늘은 <em>금리</em>가 전부", "diag": [["WHY","..."],["WHAT","..."],["ACTION","..."]]},
    "us":  {"diag": [["WHY","..."],["WHAT","..."],["ACTION","..."]]}
  }
}
```
GitHub 웹에서 파일 열기 → 연필 아이콘 → 수정 → Commit → Actions에서 Run workflow.

## 5. 추천 Top 5는 이렇게 뽑아요

시총 상위 종목(미국 약 60 · 한국 약 85 · 크립토 약 35개) 안에서 5가지 기준마다 **등수 → 0~100점** 으로 바꾼 뒤 가중 합산합니다.

| 팩터 | 비중 | 미국 | 한국 | 크립토 |
|---|---|---|---|---|
| 추세 | 20% | 200일선 위 · 50일선>200일선 | 동일 | 동일 |
| 모멘텀 | 25% | 6개월 수익률(최근 1달 제외) + 3개월 시장 대비 | 동일(코스피 대비) | 동일(BTC 대비) |
| 가치·실적 | 20% | 예상 PER 역수 + 이익 증가율 | 추정 PER 역수 + 이익 증가율 | 거래대금÷시총(거래 활력) |
| 수급 | 20% | 애널리스트 평균 평가 | 외국인+기관 20일 순매수÷시총 | 펀딩비(낮을수록 +) |
| 안정성 | 15% | 20일 변동성 낮을수록 | 동일 | 동일 |

- 한 달 −30% 넘게 빠진 종목 제외(떨어지는 칼날) · 같은 산업 최대 2개
- 진입가는 전부 **지정가**(현재가 − ATR 0.6~1배), 손익비 1:2.5 미만은 자동으로 목표가 상향 보정

## 6. 가상계좌 규칙 (자동)

- 다음 거래일 **저가 ≤ 지정가** → 체결 / 같은 날 손절가까지 빠지면 보수적으로 손절 처리
- **고가 ≥ 1차 목표** → 절반 익절 + 손절선을 매수가로(본절) / 2차 목표 → 전량 익절
- 10일 미체결 → 자동 취소 · 활성 주문 6개 미만이고 현금 30%를 지키고도 50만 원 이상 남으면 추천 1~2위로 신규 지정가(종목당 최대 150만 원)
- 원장은 `state/ledger.json` 에 매 실행마다 커밋되어 이어집니다

- 내 컴퓨터에서 테스트: `./run_local.sh` (파이썬 3만 있으면 됨, 추가 설치 없음)
